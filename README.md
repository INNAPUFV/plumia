# PlumIA · versión web (v1.8 · L)

Editor de noticias potenciado con IA para la práctica de redacción periodística.

- `plumia.html`: la aplicación (comprimida) que carga el lanzador del Canvas de Gemini.
- `src/plumia-v1.8-L.html`: código fuente legible de la misma versión.
- El lanzador que se pega en el Canvas de Gemini descarga `https://innapufv.github.io/plumia/plumia.html`.

Para publicar una versión nueva: sustituir `src/…` y `plumia.html` y subir los cambios. Todos los alumnos reciben la nueva versión con el mismo enlace de Gemini (GitHub Pages tarda unos minutos en actualizarse).
